Token de administración

Para guardar credenciales de buzones, probarlas y conectar cuentas de Microsoft desde aquí, el puente pide el token de PUENTE_ADMIN_TOKEN. Se guarda en este navegador y viaja solo al puente.

@if (admin.token()) { Hay un token guardado. }

Lo que se guarda en este navegador

La raíz del puente, los buzones agregados, qué cuentas están encendidas, las correcciones de licencias y las licencias capturadas a mano viven en el almacenamiento local de este navegador. Otro navegador (el del monitor de la oficina, por ejemplo) no las ve hasta que haya un backend para preferencias.
